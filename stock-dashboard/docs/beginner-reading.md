# 新人关联解读（Beginner Reading）

产品规格。给偏新人的使用者把已经算好的几块事实**串成一篇可读的关联说明**。

它不是新的数据源，也不是交易建议。环境、Cron、评估和模型出站纪律仍以 [DEVELOPMENT.md](../DEVELOPMENT.md)、[ROADMAP.md](../ROADMAP.md)、[README.md](../README.md) 为准。这三份文档已把本规格列为产品层并行项：不插入研究批次顺序，也不把「读一下」按钮当成模型出站入口。

契约版本：`beginner-reading-v1`

## 1. 要解决什么

当前首页是并排卡片：纳指环境、相对强弱、新闻、财报日历、历史情景、个人信号。维护者能自己拼关系；新人不能。

本功能只回答：

1. 今天这几件事是不是同一件事。
2. 哪一件还没发生，不能拿来解释今天。
3. 历史上有过类似日子的话，后来大致怎样；样本不够就明说。
4. 若你的个人纪律被触发，它和当天大盘是同向还是个股更弱。

不回答：该不该买、明天会怎样、哪条新闻「导致」了涨跌。

## 2. 是什么 / 不是什么

要做：

- 一篇固定结构的短文，指着已有字段讲关系。
- 每句都能指回现有接口或页面状态；没有字段就写「连不上」。
- **由用户点一下才生成**；打开页面、刷新行情、切日期都不得自动写出五段正文。
- 先用确定性模板，再视需要用已有研究复盘管道润色同一骨架。

不要做：

- 新概率、新归因分类、新相似日分数。
- 覆盖 `events`、`market_event_attributions`、日报 JSON 或个人决策。
- 打开页面就自动解读，或跟着自动刷新改写已经生成的正文。
- 网页按钮触发模型出站（第一期按钮只跑本地模板）。
- 聊天式荐股。
- 把运维面板（研究健康、任务账本、模型复核）塞进这篇说明。

## 3. 放在哪

| 位置 | 作用 |
|------|------|
| 首页 `marketOverview` 最上方，纳指环境卡片之前 | 「今日怎么读」 |
| 日历单日详情 `calendarDetail` 顶部 | 「这一天怎么读」；同一骨架，日期换成该市场日 |

导航可增加锚点「今日怎么读」，指向该卡片。不进入研究回放、覆盖、任务看板、归因审核、模型复核。

个人信号、持仓表、规则面板保持原样。解读里的个人段只是对照，不替代行动队列。

后续若做「简报 / 研究」视图切换：简报默认显示本卡片 + Nasdaq 环境 + 新闻 + 日历 + 个人信号；研究面板进第二层。本规格不依赖该切换，也不把它当作第一期范围。

## 3.1 只手动触发

解读是讲解，不是行情的一部分。自动出现会让新人以为这是系统给出的「正确答案」，也会在自动刷新时把正在读的文字换掉。

默认态（未点过）：

- 卡片在，五段正文不在。
- 一句话说明：把当前屏幕上的纳指、新闻、日历和你的纪律串起来读；不是预测，也不是买卖建议。
- 主按钮：**读一下今天**（单日详情为 **读一下这一天**）。
- 未点之前不调用模板函数，不请求新接口。

点过之后：

- 用**点击那一刻**页面上已经有的数据生成五段，并显示生成时间。
- 行情自动刷新、后台轮询、研究面板刷新，都不得覆盖这篇正文。
- 提供 **按当前页面再读一次**：这是下一次手动触发，用那时的可见数据重算，并更新生成时间。
- 提供 **收起**：回到默认态，不保留正文。
- 切换日历日期：丢掉上一篇，回到该日的默认态，必须再点一次。
- 第一期不写入 `localStorage`、云同步或研究快照。关掉标签页即消失。

按钮在 QQQ 报价还没有时仍可点，生成结果走第 6 节「没有纳指基准」空状态，不静默禁用到让人以为功能坏了。

## 4. 固定五段

顺序固定。缺数据的段保留标题，正文用第 6 节空状态，不删段、不把后面的段顶上来冒充完整。

### 4.1 大盘

讲纳指当天环境，不讲个股。

| 句子要表达 | 字段来源 |
|------------|----------|
| QQQ 当日涨跌 | 页面行情 `quotes.QQQ.changePercent`；收盘后优先日历/研究包里该日 QQQ `changePercent` |
| 波动是否偏高 | 日历该日后视波动等级，或研究包 `marketState.volatilityLevel` |
| 七巨头篮子是否同向 | `quotes.MAGS.changePercent` 相对 QQQ |

没有 QQQ 报价：整段用空状态，不拿 MAGS 或某个股权充大盘。

### 4.2 权重股相对 QQQ

最多点名 **3** 只相对 QQQ 偏离最大的核心成分（涨得更多或跌得更多）。每只必须带对照，不能只报绝对涨跌。

| 句子要表达 | 字段来源 |
|------------|----------|
| 代码、相对 QQQ 超额 | 核心雷达报价 − `QQQ.changePercent` |
| 系统把当日线索标成哪一类 | 当日事件 `driverType` 或归因 `classification`：`market` / `company` / `mixed` / `unclear` / `insufficient_evidence` |

分类口径对新人的固定译文：

- `market`：更像跟着大盘
- `company`：相对大盘走得更明显，且有个股公开资讯
- `mixed`：大盘和个股线索同时存在
- `unclear` / `insufficient_evidence`：系统连不上单一原因

禁止把分类译成「主力出货」「资金看好」等没有字段的故事。

### 4.3 资讯和日历

把「已经发生、可用来对照今天」和「尚未发生、只在日历上」拆开。

| 句子要表达 | 字段来源 |
|------------|----------|
| 最多 2 条已关联的公开资讯标题 + 来源 | 当日统一事件 / 动态新闻，须带 URL |
| 事件与涨跌的关系只重复已有分类 | 同上 `driverType` / `classification` |
| 未来 30 天内已归档官方财报 | `GET /api/nasdaq/earnings`；首页已有「近期官方财报」 |
| 预定事项不是今天的原因 | `status = scheduled` 或 `marketDate` 晚于解读日 |

NVIDIA FY2027 Q2（`2026-08-26`）在该日收盘前必须写成预定事项，不能写成当天涨跌原因。收盘后若仍无实际业绩字段，继续当预定/已过日历项，不补「超预期」。

没有已核对财报：写「当前范围内没有已归档的官方财报事项」，不能写成「近期没有公司要发财报」。

### 4.4 历史对照

只描述已成熟相似日的经验分布，不把它说成当前预测。

| 句子要表达 | 字段来源 |
|------------|----------|
| 样本数 | `GET /api/nasdaq/current-scenario` 的 `sample.candidateCount`（上限 5） |
| 历史后 5 / 20 日中位收益与四分位 | `outcomes.return5d` / `return20d` 的 `medianPercent`、`p25Percent`、`p75Percent` |
| 历史 20 日回撤中位 | `outcomes.maxDrawdown20d.medianPercent` |
| 小样本提示 | `sample.isSmallSample === true` 时必须出现 |

单日详情改读该日相似日，不读「当前」情景接口顶替历史日。

`positiveRatePercent` 只可写成「这组历史样本里收涨的比例」，禁止写成「上涨概率」或「胜率预测」。

### 4.5 和你有关（可空）

仅当同一市场日存在个人观察记录时才写具体句子，否则用空状态「今天没有触发你设置的纪律」。

| 句子要表达 | 字段来源 |
|------------|----------|
| 哪只标的、哪种纪律 | `personal-observation-v1`：`symbol` + `kind`（`drawdown_rule` / `target_hit` / `target_near` / `relative_weakness` / `daily_drop`） |
| 和当天 QQQ 是否同向 | 该标的当日涨跌 vs QQQ 当日涨跌 |

最多 2 条观察，按现有行动队列优先级。禁止出现买入、卖出、加仓、减仓、清仓、建议仓位。动作仍只存在于个人信号和决策日志，由用户自己选。

未登录、没有持仓、没有观察：本段保持空状态，不影响前四段。

## 5. 禁止句

复用并加严 [lib/research-narrative-contract.js](../lib/research-narrative-contract.js) 的 `BANNED_NARRATIVE_PATTERNS`。模板和模型输出都要过同一套检查。

额外禁止：

- 因果：所以跌了、导致、利空落地、被消息打压
- 把 `scheduled` 财报、未来日历项写成当天驱动
- 把历史正收益频率写成当前预测概率
- 把 NDX 过期快照写成「当前完整成分」
- 目标价、止盈、止损、必涨、必跌、该买、该卖
- 使用未晋升的 Logistic / 树概率或 DeepSeek 未 `accepted` 的摘要

允许的关联用语：对照、同向、偏离、系统标记为、历史上这组样本、尚未发生、证据不足、连不上。

## 6. 空状态

| 条件 | 固定表述方向 |
|------|----------------|
| 盘中、尚无该日收盘归档 | 这是盘中对照，收盘后才会有完整日历和研究包；不把盘中价说成收盘事实 |
| QQQ 报价缺失 | 没有纳指基准，无法做关联解读 |
| 当日无事件 / 无新闻 | 今天没有可复核的公开资讯与涨跌连在一起 |
| 归因全是证据不足 | 系统没有连上单一原因，下面的卡片仍可单独看 |
| 相似日 `awaiting_target` / `insufficient_samples` | 还没有足够的已成熟历史样本，不展示经验分布 |
| 无已归档财报 | 见 4.3，不推断市场没有财报 |
| 无个人观察 | 今天没有触发你设置的纪律 |
| 模型未开启或摘要被拒 | 第一期直接走模板；第二期失败时回退模板，不留空白、不展示拒绝原文 |

## 7. 两期实现

### 第一期：确定性模板（先做）

纯函数根据第 4 节字段填中文句子。不调用模型，不写出站，不新增环境变量。

实现文件：

- `lib/beginner-reading.mjs`：输入一份只读 `readingInput`，输出 `{ version, marketDate, mode, generatedAt, sections[] }`
- **只有**「读一下今天 / 读一下这一天 / 再读一次」的 click handler 才拼 `readingInput` 并调用该函数
- 首页用点击时已在内存里的行情、当日事件、`current-scenario`、earnings、本地观察；不为解读单独拉一轮行情
- 单日详情用该日已加载的日历详情；若该日详情还没加载，按钮先加载详情再生成，仍算一次手动触发
- `app.js` 只负责默认态 / 已生成态切换和渲染，不在 `init`、`refresh`、自动刷新计时器里调用模板
- `test/beginner-reading.test.mjs`：覆盖禁止句、空状态、财报未发生、小样本、无观察；页面层测试锁定「未点击则无五段」

盘中 `mode = "intraday"`，收盘归档后 `mode = "close"`。两种模式同一五段，文案差异只在第 6 节那条盘中提示。`generatedAt` 为点击时刻，不是行情时间。

第一期已落地：`lib/beginner-reading.mjs` + 首页/日历手动按钮。打开页面只有说明和按钮；`init` / `refreshQuotes` / 自动刷新不会调用模板。

不阻塞官方事件扩充。`2026-08-24` 已对 `deepseek-v3.2` 与当前生产模型 `deepseek-v4-flash` 分别打通无项目数据探针。第一期不依赖探针。

### 第二期：同一骨架的模型润色（后做）

`deepseek-v4-flash` 网关探针已通过。第二期仍须维护者按 DEVELOPMENT.md 批准一份新的研究快照（或解读输入快照）验证之后才开始。不得把无项目数据探针当成研究出站已批准。

约束：

- 输入必须是已归档研究包，或第一期产出的 `readingInput` 快照，不得把个人持仓明细发给第三方。个人段若要润色，只发观察的 `kind` / 是否与 QQQ 同向，不发股数和成本。
- 输出必须仍是五段；模型不得增段、改分类、改数字。
- 继续走引用校验、禁止句、追加审计、每日次数上限。
- 「读一下」按钮在第二期默认仍只跑模板。模型润色不由这个按钮出站，除非本文件修订为单独的、带确认的第二动作。
- 只有 `accepted` 才允许替换模板正文；否则保持第一期文案。
- 现有 `research-narrative-v1` 可复用审计表，或出 `beginner-reading-v1` 的平行契约。不得把未校验的 `recap` 直接贴到首页。

第二期不在本文件未修订前开始。

## 8. 验收

第一期完成当且仅当：

1. 打开页面时只有说明和按钮，没有五段正文。
2. 用户点击后才出现五段；缺数据时仍五段 + 空状态。
3. 点击后自动刷新行情不改写正文；必须再点「再读一次」才会用新数据重算。
4. 切换日历日期后正文消失，需重新点击。
5. 每句数字与分类和**点击时**同屏已有卡片一致，测试锁定不得编造字段。
6. `scheduled` 财报在解读日之前不能出现在「解释今天」的句子里。
7. 含禁止词的输出被拒绝；模板函数对含「该买 / 所以跌了 / 上涨概率」的拼接失败。
8. 无观察时不出现任何操作暗示。
9. 研究运维区无变化；模型开关保持关闭时页面仍完整可用。

## 9. 明确不做（本规格范围外）

- 扩充 IR 财报覆盖、更新 NDX 快照、把宏观写入相似日特征（仍按 ROADMAP 下一开发批次）
- 打开 DeepSeek 研究复盘作为本卡片的依赖
- 个性化纪律统计、PWA、邮件/飞书推送
- 为新人重写全部英文 eyebrow；若做简报视图，另开规格
