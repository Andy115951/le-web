# NDX Official Source Check - 2026-09-15

## Purpose

This is a read-only source availability check. It is not an NDX constituent
candidate and must not be passed to `ndx:review` or `ndx:import`.

## Observed official sources

- Nasdaq NDX weighting page: <https://indexes.nasdaq.com/Index/Weighting/NDX>
  - Checked on 2026-09-15.
  - The public page showed index data as of 2026-09-11 and a forward
    pro-forma date range beginning 2026-09-15.
  - The page states that full data requires login. Its unauthenticated output
    does not provide a complete auditable constituent-and-weight table.
- Nasdaq NDX industry breakdown: <https://indexes.nasdaq.com/Index/Breakdown/NDX>
  - Checked on 2026-09-15.
  - The public page likewise requires login for full access.
  - It therefore cannot be used to attach per-security industry labels or to
    build a historical sector mapping.
- Nasdaq NDX overview: <https://indexes.nasdaq.com/Index/Overview/NDX>
  - The public overview confirms current index-level data, but it is not a
    complete constituent-and-weight export.

## Result

No new candidate was created. No database write, import, authenticated access,
or source scraping was performed. The public pages prove that the local
`2026-05-01` snapshot is stale for current-coverage purposes, but do not meet
the project's full-source requirement.

## Required next step

1. Obtain one complete official Nasdaq constituent-and-weight export through
   authorized access, with a clear effective date and publication time.
2. Create `data/ndx/candidates/<effective-date>.json` using the existing schema.
3. Run `npm run ndx:review -- data/ndx/candidates/<effective-date>.json --output data/ndx/reviews/<effective-date>.json`.
4. Inspect the diff, then use the separate explicit `--approve` import only
