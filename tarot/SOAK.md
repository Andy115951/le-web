# P43 真机浸泡清单

整条路径走通：起卦 → 仪式 → 解读 → 追问 → 分享 → 主屏安装。  
专修卡顿、文案硌、按钮藏太深；**不新开大功能**。对外文案用「占卜 / 牌阵 / 解读」，禁「塔罗」。

## 起卦

- [ ] 首页「开始占卜」/ 场景卡进入新占卜表单，示例问题与场景一致
- [ ] 「快速起卦」一键进仪式（示例问题 + 默认牌阵）；额度用尽时有提示与登录入口
- [ ] 「牌阵与仪式（可选）」默认折叠；展开可改牌阵 / 简要详细 / 速度 / 静默
- [ ] 场景剧场软提示可一键改用推荐牌阵（感情·人际 / 日常抉择 / 身心）
- [ ] 确认起卦后进入解读页；额度 429 时文案温柔、访客可去登录

## 仪式

- [ ] 慢 / 常 / 快节奏可感；不可跳过；`prefers-reduced-motion` 时不过度动画
- [ ] 开场旁白与落烛文案出现且与场景贴合（P39）
- [ ] 牌面逐张揭晓；凯尔特十字等大阵在窄屏可读、不严重错位
- [ ] 静默模式：揭晓后不自动解读，可见「请烛火开口」

## 解读

- [ ] 非静默：揭晓后自动流式解读；失败时有「再试一次」，不卡死
- [ ] 静默：点 CTA 后流式出现；顾问气泡 Markdown 可读
- [ ] 同题旧卦轻提（若有）仅开篇一句，不复述旧全文
- [ ] 回看对照（若有同题上一卦）并排可见
- [ ] 顶栏「新占卜」常在；分享 / 信物在解读出现后有独立条，不与徽章挤成一团

## 追问

- [ ] 文字追问发送与流式回复正常；桌面 Enter 发送、Shift/Ctrl+Enter 换行
- [ ] 「抽一张象征牌」计 1 次额度，可留空文；气泡标签为「象征牌 · 追问」
- [ ] 「抽象征牌链」计 3 次；剩余不足时拦截并说明
- [ ] 额度将近 / 用尽时 QuotaHint 可见；访客有「去登录」
- [ ] 主题漂移时「新占卜」软提示可关、不强制

## 分享

- [ ] 「分享牌阵」：系统分享或复制文字摘要（无账号 / 内部 id）
- [ ] 「分享图」：先预览再保存 / 系统分享；版式烛光、牌名清晰
- [ ] 「烛火信物」：竖版预览可保存 / 分享；短签可读

## 主屏安装（PWA）

- [ ] 设置 → 关于：有添加主屏幕提示（iOS / Android 一句即可）
- [ ] 生产可安装 / 独立窗口打开；弱网下首页壳仍可用（不要求 API 离线）
- [ ] Manifest / 图标 / 主题色正常；开发环境不强制注册 SW
