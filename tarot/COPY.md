# Candle Taro — 文案与语气（v1.11）

## 产品名
- 显示名：**Candle Taro**
- 禁止对外文案出现「塔罗」二字；可用：占卜、牌阵、解读、起卦、新占卜、象征牌、烛火信物

## 六场景示例问题（可编辑）
- 感情：我们之间，接下来最需要看清的是什么？
- 事业：眼下这份工作/方向，我该如何走下一步？
- 学业：最近的学习状态，哪里卡住了？
- 人际：这段关系里，我该调整的是什么？
- 日常抉择：面对这个选择，当下更值得听从的是什么？
- 身心状态：我的身心此刻最需要被照顾的是哪一块？

## 场景语气（提示词用）
共用底线：用「可能 / 倾向 / 值得留意」；禁止「必将 / 一定会」等绝对预言。

- 感情：以轻声、体贴的烛边私语回应；多看见情绪与关系张力，少下判断。
- 事业：语气沉稳、有边界；重路径与取舍，少煽情比喻。
- 学业：鼓励但不催促；点明卡点与可执行的一小步。
- 人际：中性冷静；帮助看清互动模式与自己的位置。
- 日常抉择：短、清、点到为止；直接给对照，不铺长叙事。
- 身心状态：温柔、慢；强调照顾与边界，不制造恐慌。

## 启动 / 空状态（已锁定）
- 首页副标题：`烛火未熄。选一个场景，把问题轻轻放下；牌阵会替你照见当下。`
- 历史空状态标题：`烛火还安静着`
- 历史空状态说明：`还没有留下占卜记录。点亮一盏烛火，把问题轻轻放下；解读会出现在这里。`
- 新占卜页引导：`选好场景，把问题轻轻放下；确认后开始仪式，牌面会在静心里揭晓。`

## 访客历史
登录后自动将本机访客占卜记录合并到账号。

## 登录 / OAuth（P34）
- 登录页说明（登录态）：`用户名密码，或使用下方第三方账号。`
- 注册页说明：`用户名 + 密码即可，无需邮箱。`
- 额度提示：`登录后历史会合并到账号，每日额度提升为 10 次新占卜 / 100 次追问。访客也可直接起卦。`
- 分隔：`或使用`
- 按钮：`使用 GitHub 继续` / `使用 Google 继续`（环境变量齐全才显示；缺省隐藏，不报错）
- OAuth 失败：`第三方登录未完成，请再试一次或使用用户名密码。`
- 通用失败：`登录未成功，请再试一次。`
- 设置账号身份：`GitHub` / `Google` / `用户名密码`

## 分享（P11 + P12）
- 文字按钮：`分享牌阵` → 成功 `已复制` / `已分享`；失败 `未能分享`
- 图片按钮：`保存分享图` → 进行中 `生成中…`；成功 `已保存` / `已分享图`；失败 `未能出图`
- 文字摘要含：产品名、问题、场景、牌阵、各位牌名（正/逆位）、娱乐免责；不含账号与内部 id
- 分享图同隐私规则；竖图烛光风格；有混合位图则用牌面图，否则示意回退

## 追问子牌阵（P28）
- 按钮：`抽一张象征牌`（文字可选；空文仍可发送）
- 消耗：1 次追问额度
- 气泡：展示 compact 牌面 + 方位/正逆；编码头不对用户展示
- 占位：`象征牌抽取中…` / 标签 `子牌阵 · 追问`

## 象征牌链（P35）
- 按钮：`抽象征牌链`（文字可选；空文仍可发送）
- 消耗：3 次追问额度；剩余 <3 时：`抽象征牌链需要至少 3 次追问额度，今日剩余不足。`
- 气泡：三张 compact 牌面 + 象征一/二/三 + 正逆；编码头不对用户展示
- 占位：`象征牌链抽取中…` / 标签 `象征牌链 · 追问`
- 默认空文提示：`请结合这三条象征牌链，回应我此刻的追问。`

## 牌阵剧场（P29）
- 可选：`关系双人` / `抉择分叉` / `月相三问`（默认仍为三牌；日常抉择默认单牌）
- 场景软提示（未改用时显示，可一点「改用…」）：
  - 感情：`感情局也可试「关系双人」：我方 / 对方 / 关系纽带。`
  - 人际：`人际局也可试「关系双人」：我方 / 对方 / 关系纽带。`
  - 日常抉择：`日常抉择也可试「抉择分叉」：路径甲 / 路径乙 / 关键建议。`
  - 身心状态：`身心局也可试「月相三问」：隐流 / 显象 / 应时之举。`

## 烛火信物（P30）
- 按钮：`烛火信物` → 进行中 `点亮中…`；成功 `已保存` / `已分享`；失败 `未能点亮`
- 竖版壁纸（约 9:16）+ 中文短签；不含账号与内部 id

## 额度与软重抽（P14）
- 额度一行：`今日额度：新占卜 a/b · 追问 c/d`
- 近耗尽（剩余 ≤1）：`今日新占卜只剩最后一点烛火，且行且惜。` / `今日追问只剩最后一两次，可以把问题问得更具体一点。`
- 用尽（登录）：`今日新占卜额度已用尽，明天再来点亮一盏吧。` / `今日追问额度已用尽，可以先回看这卦，或明天再续。`
- 用尽（访客）：`访客今日起卦额度已用尽，请登录后继续。` / `访客追问额度已用尽，请登录后继续。`
- 登录引导：`去登录，历史会自动合并，额度也会更宽裕。`
- 软重抽 chip：顾问已提示 → `话题似乎换了。若想另起一卦，可以轻轻点亮新烛火。`；追问≥2 → `追问已经走了一段。若主题变了，建议重新起卦，牌面会更贴切。`；按钮 `先留下` / `新占卜`

## 静默模式（P36）
- 设置 / 起卦：`自动解读` / `静默模式`（默认自动）
- 静默等待提示：`先静静看牌，准备好再请烛火开口`
- CTA：`请烛火开口`
- 徽章：`静默`

## 今日一牌（首页）

- 标题：`今日一牌`
- 说明：`不计入占卜额度，只作今日提示；想深入可去看牌义或起一卦。`
- CTA：`查看牌义` / `开始占卜`

## 解读 Markdown（P38）

- 顾问解读/追问可含轻量 Markdown（`##` 小节、`**强调**`、`-` 列表）；用户气泡仍纯文本
- 小节标题优先：总览 / 牌意 / 综合 / 建议
- 禁代码围栏、表格、HTML；对外文案仍禁「塔罗」

## 快速起卦 / 流程缩短（P37）
- 首页场景卡次要按钮：`快速起卦` → 进行中 `起卦中…`；额度用尽 `今日额度已用尽`
- 行为：用该场景示例问题 + 场景默认牌阵 + 用户偏好（解读/速度/静默）直接创建并进入解读；卡片本体仍进新占卜表单可改
- 英雄区：可对「日常抉择」一键快速起卦；说明：`快速起卦用「日常抉择」示例问题与默认单牌；想改问题请点场景卡片。`
- 起卦表单折叠标题：`牌阵与仪式（可选）`；折叠态辅助：`展开` / `收起` + 当前牌阵名
- 自定义场景无示例问题，不展示快速起卦
