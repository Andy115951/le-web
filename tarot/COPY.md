# Candle Taro — 文案与语气（v1.19）

## 产品名
- 显示名：**Candle Taro**
- 禁止对外文案出现「塔罗」二字；可用：占卜、牌阵、解读、起卦、新占卜、象征牌、烛火信物

## 六场景示例问题（可编辑）
- 感情：我们之间，接下来最需要看清的是什么？
- 事业：眼下这份工作/方向，我该如何走下一步？
- 学业：最近的学习状态，哪里卡住了？
- 人际：这段关系里，我该调整的是什么？
- 日常抉择：面对这个选择，当下更值得听从的是什么？
- 身心状态：我的身心此刻最需要被照顾的是哪一块？

## 场景语气（提示词用 · P47 再校准）
共用底线：用「可能 / 倾向 / 值得留意」；禁止「必将 / 一定会」等绝对预言。场景口吻必须可辨认（贯穿解读总览与综合）。

- 感情：口吻偏柔——像烛边低语，优先看见情绪与关系张力；少下对错判断，多用「可能感到」「值得留意」。
- 事业：口吻偏稳——沉稳有边界，像安静桌上谈路径与取舍；少煽情比喻，多对照「能做的一步」与「暂缓的」。
- 学业：口吻偏鼓励但不催——点明卡点后只给一个可执行的一小步；忌长篇说教。
- 人际：口吻偏中性冷静——帮看清互动模式与自己的位置；少站队、少情绪渲染。
- 日常抉择：口吻偏短直——一两句对照即可，不铺叙事；先摆两边，再点「当下更值得听从的」。
- 身心状态：口吻偏慢柔——强调照顾与边界，像慢烛火；不制造恐慌，不诊断。
- 自定义：口吻温和、具体——以本局牌阵为锚，可延伸为顾问对话；勿写成泛化鸡汤。


## 场景微剧本（P39）
仪式面板在揭晓前显示「开场旁白」，牌落定后显示「落烛」；数据在 `scenes.ts`（`opening` / `settle`）。

- 感情：开场 `烛火靠得近些。把心里那句还没说清的话，轻轻放在灯芯旁。` / 落烛 `牌已落定。别急着定论，先听关系里那一点细微的回响。`
- 事业：开场 `烛火稳一点。把方向与取舍，摊开在这张安静的桌上。` / 落烛 `牌已落定。看清路径的轮廓即可，不必把下一步说成必然。`
- 学业：开场 `烛火不催。把卡住的地方放到光里，慢慢看一眼。` / 落烛 `牌已落定。先认一小步可走的地方，比一次走完更重要。`
- 人际：开场 `烛火中性。先看清你站在哪里，再看互动怎么绕。` / 落烛 `牌已落定。模式比对错更值得留意。`
- 日常抉择：开场 `烛火短亮一下。把抉择放轻，只问当下更值得听从的是什么。` / 落烛 `牌已落定。对照已经在此，不必再铺长篇。`
- 身心状态：开场 `烛火慢一点。把身心需要被照顾的那一块，交给这点暖光。` / 落烛 `牌已落定。先照顾边界与呼吸，不制造恐慌。`
- 自定义：开场 `烛火亮着。把问题轻轻放下，让牌阵替你照见当下。` / 落烛 `牌已落定。以这阵为锚，可再慢慢追问。`

## 登录 / OAuth（P34）
- 登录页说明（登录态）：`用户名密码，或使用下方第三方账号。`
- 注册页说明：`用户名 + 密码即可，无需邮箱。`
- 额度提示：`登录后历史会合并到账号，每日额度提升为 10 次新占卜 / 100 次追问。访客也可直接起卦。`
- 分隔：`或使用用户名`（第三方按钮置顶，缩短访客转化路径）
- 按钮：`使用 GitHub 继续` / `使用 Google 继续`（环境变量齐全才显示；缺省隐藏，不报错）
- OAuth 失败：`第三方登录未完成，请再试一次或使用用户名密码。`
- 通用失败：`登录未成功，请再试一次。`
- 设置账号身份：`GitHub` / `Google` / `用户名密码`

## 分享（P11 + P12 + P40）
- 文字按钮：`分享牌阵` → 成功 `已复制` / `已分享`；失败 `未能分享`（取消分享静默）
- 图片按钮：`分享图` → 进行中 `生成中…`；失败 `未能出图`（预览后再保存 / 系统分享）
- 出图后弹出预览：`保存图片` / `系统分享`（`navigator.share` + files，不可用时按钮灰显）/ `关闭`；取消系统分享静默
- 文字摘要（朋友圈向）：产品名、今晚这一问、场景·牌阵、烛下牌面（正/逆位）、镜子免责与温暖落款；不含账号、cookie、内部 id、AI 细节
- 分享图同隐私规则；竖图烛光风格；有混合位图则用牌面图，否则示意回退

## 追问子牌阵（P28）
- 按钮：`抽一张象征牌`（文字可选；空文仍可发送）
- 消耗：1 次追问额度
- 气泡：展示 compact 牌面 + 方位/正逆；编码头不对用户展示
- 占位：`象征牌抽取中…` / 标签 `象征牌 · 追问`

## 象征牌链（P35）
- 按钮：`抽象征牌链`（文字可选；空文仍可发送）
- 消耗：3 次追问额度；剩余 <3 时：`抽象征牌链需要至少 3 次追问额度，今日剩余不足。`
- 气泡：三张 compact 牌面 + 象征一/二/三 + 正逆；编码头不对用户展示
- 占位：`象征牌链抽取中…` / 标签 `象征牌链 · 追问`
- 默认空文提示：`请结合这三条象征牌链，回应我此刻的追问。`

## 牌阵剧场（P29）
- 可选：`关系双人` / `抉择分叉` / `月相三问`（默认仍为三牌；日常抉择默认单牌）

  - 人际：`人际局也可试「关系双人」：我方 / 对方 / 关系纽带。`

## 烛火信物（P30 + P40）
- 按钮：`烛火信物` → 进行中 `点亮中…`；失败 `未能点亮`
- 点亮后同分享图：预览 → `保存图片` / `系统分享` / `关闭`；取消系统分享静默
- 竖版壁纸（1080×1920）+ 中文短签；版式：品牌头、焦点牌框、短签可读区、品牌脚注；不含账号与内部 id

## 额度与软重抽（P14 + P45）
- 额度一行：`今日额度：新占卜 a/b · 追问 c/d`
- 近耗尽（登录）：`今日新占卜只剩最后一点烛火，且行且惜。` / `今日追问只剩最后一两次，可以把问题问得更具体一点。`
- 近耗尽（访客）：`今日起卦只剩最后一点烛火。想留更多空间，可以先轻轻登录。` / `今日追问只剩最后一两次。登录后额度会更宽裕。`
- 用尽（登录）：`今日新占卜额度已用尽，明天再来点亮一盏吧。` / `今日追问额度已用尽，可以先回看这卦，或明天再续。`
- 用尽（访客）：`访客今日起卦的烛火已用尽。登录后可以继续点亮，历史也会安静合并。` / `访客今日追问的烛火已用尽。登录后还能轻声多问几句。`
- 登录 CTA（就近按钮）：`轻轻登录`；可选一键：`使用 GitHub 继续`（环境变量齐全才显示；Google 仍可选，缺省不阻塞）
- CTA 旁白：`轻轻登录，马上可以继续起卦/追问；历史会合并，每日额度也会更宽。`
- 脚注：`访客记录会安静并入账号 · 不改今日已用额度数字`
- 登录后回跳：`?next=` 回到起卦/解读页（OAuth 同步带回）
- 软重抽 chip：顾问已提示 → `话题似乎换了。若想另起一卦，可以轻轻点亮新烛火。`；追问≥2 → `追问已经走了一段。若主题变了，建议重新起卦，牌面会更贴切。`；按钮 `先留下` / `新占卜`

- CTA：`查看牌义` / `开始占卜`

## 解读 Markdown（P38 + P47）

- 顾问解读/追问可含轻量 Markdown（`##` 小节、`**强调**`、`-` 列表）；用户气泡仍纯文本
- 解读固定顺序：`## 总览` → `## 牌意` → `## 综合`；简要档仅此三节；详细档可在综合后加 `## 建议`
- 勿改用飘移小节名；场景口吻须在总览可辨认
- 禁代码围栏、表格、HTML；对外文案仍禁「塔罗」

## 快速起卦 / 流程缩短（P37）
- 首页场景卡次要按钮：`快速起卦` → 进行中 `起卦中…`；额度用尽 `今日额度已用尽`
- 行为：用该场景示例问题 + 场景默认牌阵 + 用户偏好（解读/速度/静默）直接创建并进入解读；卡片本体仍进新占卜表单可改
- 英雄区：可对「日常抉择」一键快速起卦；说明：`快速起卦用「日常抉择」示例问题与默认单牌；想改问题请点场景卡片。`
- 起卦表单折叠标题：`牌阵与仪式（可选）`；折叠态辅助：`展开` / `收起` + 当前牌阵名
- 自定义场景无示例问题，不展示快速起卦


## 同题旧卦轻提（P41）
- 若同一账号/访客曾问过相同问题，解读开篇可轻提一句（如「你上次问过类似的问题…」），随后仍以本局牌面为主；不复述旧解读全文，不做跨局长记忆聊天

## 访客→登录转化（P45）

- 触发：访客额度将近用尽 / 用尽（额度提示、新占卜页、追问区、首页用尽、快速起卦失败）
- 路径更短：就近「轻轻登录」按钮 + 可选 GitHub 一键；登录/OAuth 后经 `next` 回到原页
- 不改额度数字；Google 仍可选；禁「塔罗」

## 历史好找（P46）

- 筛选：场景（全部 / 六场景 / 自定义）；时间（全部 / 近 7 天 / 近 30 天 / 更早）；`只看收藏`；`清除筛选`
- 同题成组：标题 `同题 · N 局`；操作 `展开其余 N 局` / `收起同题`
- 软收藏：星标按钮；徽章 `收藏`；旁注 `收藏存在本机烛火旁（此设备）；同题会轻轻拢在一起。`
- 筛选空态标题：`烛火里暂时没有符合的记录`
- 筛选空态说明：`换个场景或时间再看看，或先点亮一盏星标。`
- 禁「塔罗」
