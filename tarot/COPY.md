# Candle Taro — 文案与语气（v1.4）

## 产品名
- 显示名：**Candle Taro**
- 禁止对外文案出现「塔罗」二字；可用：占卜、牌阵、解读、起卦、新占卜

## 六场景示例问题（可编辑）
- 感情：我们之间，接下来最需要看清的是什么？
- 事业：眼下这份工作/方向，我该如何走下一步？
- 学业：最近的学习状态，哪里卡住了？
- 人际：这段关系里，我该调整的是什么？
- 日常抉择：面对这个选择，当下更值得听从的是什么？
- 身心状态：我的身心此刻最需要被照顾的是哪一块？

## 场景语气（提示词用）
共用底线：用「可能 / 倾向 / 值得留意」；禁止「必将 / 一定会」等绝对预言。

- 感情：以轻声、体贴的烛边私语回应；多看见情绪与关系张力，少下判断。
- 事业：语气沉稳、有边界；重路径与取舍，少煽情比喻。
- 学业：鼓励但不催促；点明卡点与可执行的一小步。
- 人际：中性冷静；帮助看清互动模式与自己的位置。
- 日常抉择：短、清、点到为止；直接给对照，不铺长叙事。
- 身心状态：温柔、慢；强调照顾与边界，不制造恐慌。
