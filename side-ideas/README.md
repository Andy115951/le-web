## 这个目录干什么

点子、原则、还没做成货的项目。做成了能打包发出去的，放到 `sell-lab`。

| 文件 | 用途 |
|---|---|
| [想法池.md](./想法池.md) | 所有点子，先堆着 |
| [../sell-lab/README.md](../sell-lab/README.md) | 卖货实验室 |
| [小工具-闲鱼.md](./小工具-闲鱼.md) | 本地小工具口径；做成再搬进 sell-lab |
| [血糖小助手.md](./血糖小助手.md) | 自用，不是闲钱挂品 |
| [含金量方向.md](./含金量方向.md) | 按本地 code 看什么值得换钱 |
| [时间追踪-重做.md](./时间追踪-重做.md) | Timing Lite 改名收窄 |

有新想法丢进 `想法池.md`。真要上架，产出落到 `sell-lab`。
