# 小工具 · 闲鱼

状态：下次周末可试（和 PPT、Word 三选一先开）  
目标：一样，一个月 2 单 9.9 就够

卖的是 **本地就能跑的小工具**，不是网站、不是插件商店、不是要你托管的服务。买家解压，用浏览器打开 `index.html`。

和 [html-以后.md](./html-以后.md) 的差别：请柬是改字再发出去；工具是打开就用，不用改代码。

## 做成什么样

一条商品 = 一个明确用途，不要「效率工具 100 合 1」。

每份 zip 里固定有：

1. `index.html`（能双击打开；数据只存在浏览器本地）
2. 需要的话再带 `style.css` / `app.js`，不要 `npm install`
3. `使用说明.txt`：怎么打开、数据存在哪、不联网也能不能用
4. 一张预览图（真实界面截图）

不登录、不强制联网、不收集信息。需要「保存」就用 `localStorage`。售后统一回复：按说明用浏览器打开，不代改功能。

## 先做哪几个

一个周末 1 个能跑的就够，最多再顺手打一个包。

| 工具 | 谁会搜 | 从哪来 |
|---|---|---|
| 随机点名 / 抽签 | 老师、班委、活动主持 | 新做，一页就够 |
| 聚会分账 | 聚餐后算钱 | 新做 |
| 考试 / 答辩倒计时 | 学生赶日期 | 新做 |
| 本地图片压缩、改尺寸 | 要上传、要发闲鱼主图的人 | 新做（纯前端） |
| 四象限待办 | 想把事分一下的人 | `quadrant-todo` 去掉登录和后端 |
| 专注计时 / 番茄钟 | 上班、备考 | `timing-lite-tauri` 的网页瘦身版，不要先做安装包 |

摸鱼工资条、抽奖转盘也可以记着，别一个周末做一打。

现有项目里先别拆去卖的：

- `fitness-app`：绑了账号和后端
- `stock-dashboard`：自己用的，售后会变成「帮我看盘」
- `desktop-pet`：好玩，不像刚需
- Tauri 安装包：签名、系统误报，主业边上不划算
