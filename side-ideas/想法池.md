## 可以记着

后面要加，也挂在同一批「办公 / 交差」需求上，别另开赛道。

### HTML / H5 展示页

请柬、作品集、小商家介绍。和「小工具」不是一类：这个要买家改内容再发出去，工具是打开就用。

见 [../sell-lab/html-以后.md](../sell-lab/html-以后.md)。出过单再做。

### 办公表格包

Excel：考勤、报销、班级成绩、简单进销存。比 PPT 更「打开就能填」，售后可能更少。先记着，别跟 PPT 一起上。

### 作品集页

一页 HTML。简历本身归 Word，见上面。和答辩包、个人页是近亲。

### 电子请柬 / 活动签到页

婚礼、同学聚会、部门团建。有截止日期，比通用模板更可能有人买；也可以做成「改文字就能用」的 HTML。

### 小红书 / 公众号封面结构包

不是爆款设计服务，是固定尺寸的封面框（标题区、配色、安全边距）。和 PPT 一样，只卖成品不改图。

### 通用 AI 提示词（走量，和公司无关）

12 则办公常用指令，复制进任意对话框。不是公司 skill，不是 999 条大全。

第一包已出： [../sell-lab/prompt-pack/office-prompts/](../sell-lab/prompt-pack/office-prompts/)。口径见 [../sell-lab/提示词.md](../sell-lab/提示词.md)。

### 从现有 le-web 项目顺手拆

能当工具卖的、能当展示页卖的，分别写在 [小工具-闲鱼.md](./小工具-闲鱼.md) 和 [../sell-lab/html-以后.md](../sell-lab/html-以后.md)。拆之前先问：陌生人搜得到吗？打开就能用吗？需要我托管吗？需要托管就先不做。

## 先不做

| 点子 | 原因 |
|---|---|
| 通用「9999 套 PPT / Word」大礼包 | 红海、搬运多、单价低、版权脏 |
| 闲鱼 PPT / Word 定制、代写、包修改 | 晚上会被改稿拖死 |
| 合同、协议、法律文书模板 | 不像办公交差件，有人拿去当真的，别碰 |
| 拼多多虚拟店 | 保证金、白嫖退款、客服，为了奶茶钱不值 |
| 卖别人的模板 / 网课 / 资料合集 | 版权 |
| AI 教程、提示词大全（999 条那种） | 同质化极高。走量通用包见 sell-lab/提示词.md |
| 接企业外包、包月改稿 | 这是主业的形状，不是闲钱 |
| 要服务器 / 登录 / API Key 的工具 | 你得一直养着，不是挂上去就不管 |
| 桌面安装包、浏览器插件先上架 | 签名、误报、审核，一个周末收不掉 |
| AI 中转、账号、破解类工具 | 别碰 |
| 血糖助手做成「预测餐后曲线 / 替代医嘱」 | 说不准，还有合规风险 |
| 一上来做带账号的血糖 SaaS | 养数据库、养用户，主业边上扛不住 |
| 把 `stock-dashboard` 做成荐股 / 信号会员 | 合规和声誉都不划算，看板自己已经在避这个 |
| 四象限 Todo、桌宠做成订阅制大产品 | 赛道熟、获客贵，现有完成度撑不起 |
| 和主业同一摊对外接活、写内部细节 | 先确认能不能做，默认不做 |
| 外售 Chatbox 用例 / 客服手册 / 分析流水线 / 测试 skill | 公司资产 |
| 小红书自动私信、油猴获客脚本 | 平台规则和骚扰风险 |
| 把 Triton 组会稿当成主业去卖课 | `code` 里没有对应工程，看窄了 |
| 第一期做成 WakaTime：多端同步 + 网页看板 | 插件生态和托管，不是窗口采集加两页；Wakapi 已占自建后端 |
