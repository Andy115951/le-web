## 更值得做的（按匹配度，已按完整 code 重排）

### 1. AI 产品的测试设计 + 桌面端 E2E

这是别人看你仓库最不该忽略的能力：Electron 应用怎么测、模型/供应商矩阵怎么铺、发版回归怎么拆，以及 **先写口径再写用例** 的那两步 skill。

会写页面的人很多；能给一个带模型列表、流式输出、套餐、桌面壳的 AI 产品搭测试的人少。客单是咨询/搭框架级别，不是 9.9。

能换钱的形态（都要避开 Chatbox 内部）：

- 帮别的 Electron / 桌面客户端搭 Playwright 冒烟 + 回归
- 帮小团队建「step1 建模 → step2 用例表」的测试文档习惯
- 按天：测一轮他们的模型接入（能不能连、流式、思考模式、失败怎么展示）

**红线：** 不卖 Chatbox 用例、选择器、客服手册、用户数据；不给正竞品做「对着 Chatbox 抄测试」。用的是方法，不是公司资产。

### 2. 产品化接单（小系统，一年几单）

和主业不抢活的交付：小程序转 Web、Vercel + 登录的个人/小团队工具、Tauri 本地小软件。`shu-date`、`mini-love-web`、`quadrant-todo`、`timing-lite` 证明你能交上去能用的东西。

报价按系统，不按改稿。即刻 / 电鸭 / V2EX / 熟人。

### 3. 时间追踪：改名收口，不当 Timing Lite

市面上已有 Timing、Timemator、RescueTime、ActivityWatch。现有仓叫 Timing Lite，看起来像仿品，**名字和定位必须换**，采集内核不用推倒。

不要做成更瘦的 Timing，也不要第一期做成 WakaTime（多端同步 + 网页看板）。那是插件生态和托管服务，不是窗口采集加两页。收成：本地、买断、中文、用规则把窗口归到「主业 / 自己的项目」。口径见 [时间追踪-重做.md](./时间追踪-重做.md)。

### 4. 反馈 / 客服 agent 这种工作流（往后放）

`chatbox-feedback` + `support-agent-kit` + `chatbox-analysis` 连起来，其实是「用户说话 → 分类 → 回邮件 → 内部周报」。很多 AI 小团队缺这个。

但这和主业重叠最大：数据、政策、实现都容易带上公司的。除非以后完全用自己的新项目重写一版，否则先不要对外卖。

### 5. Triton / torch.compile 讲解 — 降级为旁支

只在 `le-web/doc` 里有一份组会稿，`code` 里没有对应工程仓。不能再当成主技能去卖。真是自己的业余研究、只用公开数据，可以写公开文章；不要默认这是能报价的主路径。

## 不建议当成盈利手段

| 想法 | 原因 |
|---|---|
| 把 `stock-dashboard` 做成荐股会员 | 合规和声誉；看板自己已经在避「明天会怎样」 |
| 四象限 Todo、桌宠做成订阅 | 赛道熟，完成度撑不起获客 |
| 校园匹配站继续当生意 | `shu-date` 证明能上线，运营和审核会吃掉晚上 |
| 小红书自动私信 / 油猴获客 | 平台规则和骚扰风险 |
| 把 Chatbox 测试、客服、分析原样外售 | 公司资产 |
| 闲鱼低价资料当主路径 | 卖的是正在变便宜的制作能力 |
| 血糖完整 SaaS | 自用可以，当生意太重 |

## 怎么选

有主业的前提下，含金量来自 **少单、高价、用方法而不是用公司代码**。

1. 想尽快见到钱、又用得上最强技能：对外只说「桌面端 E2E / 测试建模 / 模型接入怎么验」，接 1 单看报价。
2. 想做软件、不碰主业：只收口 `timing-lite-tauri`。
3. 闲钱模板继续当零花，别升级成主线。

同一时间仍然只开一条。
