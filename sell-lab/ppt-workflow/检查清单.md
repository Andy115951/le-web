# 检查清单

上架前每一条都要能勾。过不了就改，不要用「差不多」上架。

## 内容

- [ ] 页数 8–15，和 spec 的页表一致
- [ ] 有封面、目录、内容骨架、数据/进度页、结尾、怎么改
- [ ] 没有装饰性的「名言页」「感谢观看大图页」（怎么改那页除外）
- [ ] 该换的字用统一占位（如 `【姓名】`），没有 lorem、xxxx、This page
- [ ] 图表数字是假的占位，看起来像周报而不像随机乱数
- [ ] 没有品牌 Logo、校徽、未授权插画、真人照片

## 投影和版式

- [ ] 16:9
- [ ] 标题在会议室后排大致能看清（不要小于约 28pt）
- [ ] 正文不要挤成墙；一条结论一行，不要段落作文
- [ ] 边距足够，字不贴边、不互相捅
- [ ] 深色字配浅底或反过来，灰字叠灰底不行
- [ ] 全套配色和字体是一套，不是每页换风格

## 交付

- [ ] 文件能用 PowerPoint / WPS / Keynote 打开（至少本地抽查一种）
- [ ] `怎么改.txt` 写清：改哪些占位、建议字体、别动页边距
- [ ] `listing.md` 写清页数、格式、**不改稿**
- [ ] 预览图是这套自己的内页，不是网图
