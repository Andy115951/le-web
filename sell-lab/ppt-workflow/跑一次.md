# 跑一次：做一套闲鱼 PPT 成品包

把本页整份交给 agent。把下面的 slug 换成要做的那一套（第一套用 `weekly-report`）。

**场景 slug：** `weekly-report`

## 你要做的

在仓库 `/Users/apple/Documents/code/other/le-web` 里，按 `sell-lab/ppt-workflow/` 这套流程，为上面的 slug 产出一套可上架的成品包。

1. 读 `sell-lab/ppt-workflow/scenes/<slug>/spec.md`。没有这份文件就停，先让人写 spec。
2. 按 `prompts/01-大纲.md` 写出大纲，落到 `packs/<slug>/outline.md`。页数、页名必须和 spec 一致，不要加装饰页。
3. 按 `prompts/02-生成.md` 做出 `packs/<slug>/deck.pptx`。用 pptx 技能（PptxGenJS / 预置模板），16:9。占位字用 spec 规定的写法。做完要过视觉检查：重叠、溢出、对比度、边距。
4. 对照 `检查清单.md` 写 `packs/<slug>/qa.md`：每条过/不过。有不过就改 pptx 再记一笔。
5. 按 `prompts/03-上架.md` 写 `packs/<slug>/listing.md`。
6. 写 `packs/<slug>/怎么改.txt`（和最后一页一致）。
7. 预览图：若环境能渲 slide 图，放到 `packs/<slug>/preview/`（封面、目录、两页内容、结尾）。渲不了就在 qa.md 里写「预览需人工截」，不要用假图凑。

## 不要做

- 不要一次做多个 slug
- 不要 9999 套、不要抄闲鱼主图、不要学校/公司 Logo
- 不要代写真实业绩；内容必须是占位，买家自己填
- 不要接「再帮我改成某某公司的」——这是成品包工作流，不是定制
