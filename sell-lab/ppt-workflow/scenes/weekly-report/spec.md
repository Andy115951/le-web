# 场景：周报 / 月报

- slug: `weekly-report`
- 状态: 规格已订，成品未出
- 谁会搜: 上班的人周五晚上，要拿去周会投影
- 搜索词: 周报PPT、月报模板、工作汇报

## 一句话

打开改【】里的字，就能当这周/这月的汇报骨架，不需要从空白页开始排。

## 配色

办公浅色，不要默认蓝紫渐变。

| 用途 | hex |
|---|---|
| 背景 | `F4F1EA` |
| 卡片 | `FFFFFF` |
| 主文字 | `1F2933` |
| 次文字 | `5C6B73` |
| 强调 | `C45C26` |
| 图表 1 | `C45C26` |
| 图表 2 | `3D5A4C` |

## 占位规则

要买家填的一律 `【这样】`，例如 `【姓名】` `【本周完成 1】`。  
示例数字可以写死（如 3、5、80%），并在怎么改里说明「换成自己的」。

## 页表（11 页）

| # | 页名 | 买家填什么 | 版式 |
|---|---|---|---|
| 1 | 封面 | 【部门】【周期】【姓名】【日期】 | 封面，大标题「工作周报」小字可改成月报 |
| 2 | 目录 | 不用填，页名固定 | 目录 |
| 3 | 本周结论 | 三句：做成了什么、卡在哪、下周先做哪件 | 三张卡片 |
| 4 | 完成事项 | 4 条【事项】+ 状态 | 列表/卡片 |
| 5 | 数据进度 | 3 个【指标名】和数字 | 大数字 + 一柱状图（占位） |
| 6 | 重点工作拆解 | 1 件【重点】的进展/风险 | 左文字右三条风险 |
| 7 | 问题与支持 | 2 条【问题】和需要的支持 | 双栏 |
| 8 | 跨部门/协作 | 可选；【对象】【事项】 | 表，三行占位 |
| 9 | 下周计划 | 4 条【计划】+ 优先级 | 编号列表 |
| 10 | 结尾 | 【汇报人】【联系方式可空】 | 结束页，不要「谢谢观看」大图 |
| 11 | 怎么改 | 不填 | 说明改哪些【】、建议用微软雅黑、别改边距 |

第 8 页如果买家用不上，怎么改里写「可整页删」。不要再加行业分析页。
