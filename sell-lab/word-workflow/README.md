# Word 场景用辞工作流

周末优先跑这一条，PPT 工作流先放着。

卖的不是排版，是 **常见场景里能改着交差的句子**。纯文本为主，`.docx` 只是带标题层级，方便复制进邮件或文档。

口径见 [../word.md](../word.md)。

## 目录

| 路径 | 干什么 |
|---|---|
| [跑一次.md](./跑一次.md) | 丢给 agent 的任务书 |
| [检查清单.md](./检查清单.md) | 上架前过一遍 |
| `prompts/` | 大纲 / 生成 / 上架 |
| `scenes/<slug>/spec.md` | 这一套有哪些场景句、几种语气 |
| `packs/<slug>/` | 产出：txt、docx、上架文案 |

第一套：`weekly-phrases`（周报用辞）。请假、纪要以后再加，同一周不要开第二条。

## 一次怎么走

1. 确认 spec 已写完。
2. 把 [跑一次.md](./跑一次.md) 交给 agent，slug 换成要做的那套。
3. 人过检查清单：像不像能交差的话，不像作文、不像 AI 排比。
4. 上架。两周 0 咨询就停。

## 产出约定

每个 `packs/<slug>/` 里要有：

- `copy.txt` — 纯文本，买家打开就能改
- `copy.docx` — 同一份内容，标题用 Word 标题样式
- `怎么改.txt`
- `listing.md`
- `qa.md`
