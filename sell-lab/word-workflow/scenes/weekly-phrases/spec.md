# 场景：周报用辞

- slug: `weekly-phrases`
- 状态: 成品已出，卖多少是多少
- 谁会搜: 要交文字周报或把周报贴进邮件/群的人
- 搜索词: 周报模板、周报怎么写、工作汇报套话

## 一句话

不是一篇写好的周报，是按块准备好的句子。换成自己的【事项】就能交差。

## 块

每块给 **稳妥 / 坦诚 / 短邮** 三种语气。稳妥、坦诚各 3 条；短邮每块 1 段（可直接粘贴）。

| 块 | 买家填什么 |
|---|---|
| 开头（本周范围） | 【周期】【姓名】【部门】 |
| 本周结论 | 做成了什么、卡在哪、下周先做哪件 |
| 完成事项 | 4 条以内【事项】+ 结果 |
| 数据/进度 | 【指标】和数字，没有数就写「本周无量化指标，进展见上」 |
| 问题与支持 | 【问题】【需要的支持】 |
| 下周计划 | 4 条以内【计划】 |
| 邮件短版 | 把上面收成一封 8～12 行的邮件 |

另外固定两小段，不算三种语气：

- **可删说明**：哪块没内容就整段删
- **怎么改**：先替换【】，再删不用的语气，只留一种发出去

## 不要写进包里的

行业趋势、个人感悟、对领导的感谢、空洞「持续赋能」。
