# 检查清单

## 内容

- [ ] 全是可替换句子，不是一篇写死的「优秀周报范文」
- [ ] 占位统一 `【】`，没有 lorem、某某某、张三
- [ ] 每种语气真的不一样，不是同义反复三遍
- [ ] 没有保证升职、包过、对领导拍马的肉麻句（除非 spec 明确要「偏稳妥」且仍像正常人说话）
- [ ] 没有抄网上公文、没有学校/公司全称

## 文本

- [ ] `copy.txt` 用 UTF-8，分段清楚，复制进微信/邮件不乱码
- [ ] 句子短，能读出声；没有「赋能」「闭环」「抓手」堆砌，除非放在「可选用词」一小节并标明可选
- [ ] `copy.docx` 和 txt 内容一致，只有标题样式不同

## 交付

- [ ] `怎么改.txt` 写清：先全局替换【】，再删用不上的语气
- [ ] `listing.md` 写清：纯文本+Word、不代写、不改稿
